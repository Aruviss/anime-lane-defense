# ⚔️ Battle Anime (Battle Cats Style)

เกมแนว **Side-Scrolling Lane Defense (สไตล์ The Battle Cats)** ธีม **Anime Jump Fighters & LF2** พร้อมระบบ Endless Stages และ Character Upgrades รันบนเบราว์เซอร์ได้ทันที

---

## 🎮 วิธีเปิดเล่นเกม (เลือกวิธีใดวิธีหนึ่ง)

### วิธีที่ 1: ดับเบิ้ลคลิกเปิดเล่นได้ทันที (ง่ายที่สุด)
* ดับเบิ้ลคลิกที่ไฟล์ **`index.html`** ในโฟลเดอร์นี้เพื่อเล่นผ่าน Chrome, Edge หรือเบราว์เซอร์ใดก็ได้

### วิธีที่ 2: รันผ่าน Local Server
* ดับเบิ้ลคลิกไฟล์ **`start.bat`** (หรือพิมพ์ `python server.py` ใน Terminal)
* เบราว์เซอร์จะเปิดหน้าเกมที่ `http://localhost:8080` ให้โดยอัตโนมัติ

## 🕹️ การควบคุมและระบบเกมเพลย์

| ปุ่ม / การกระทำ | หน้าที่ |
| :--- | :--- |
| **ลากเมาส์ / จอทัช** หรือปุ่ม **A / D** | เลื่อนมุมกล้องไปซ้าย-ขวาบนสนามรบ |
| **เลข 1, 2, 3, 4** หรือคลิกที่การ์ด | ส่งยูนิตตัวละครลงสนาม (มีภาพ Portrait จาก LF2) |
| **ปุ่ม E** หรือคลิกที่ปุ่มเลเวลด้านบน | อัปเกรดเตาพลังงาน (Aether Reactor) เพื่อเพิ่ม Max Mana และความเร็วในการผลิต |
| **Spacebar** หรือคลิกปุ่มสายฟ้า | ยิงปืนใหญ่ **Aether Cannon** ยิงลำแสงล้างสนามพร้อมผลักศัตรูกระเด็น |
| **ปุ่ม 1.0x / 2.0x Speed** | ปรับความเร็วเกมเป็น 2 เท่า |
| **ปุ่ม Sound** | เปิด/ปิดเสียงเอฟเฟกต์และดนตรีสังเคราะห์ (Web Audio API) |

   * ราคา 85 | คูลดาวน์ 2.2s | HP 550 | ATK 45

   * ราคา 950 | คูลดาวน์ 12s | HP 550 | ATK 360

4. **LouisEX (จอมทัพเทพเกราะทอง)** - *Uber Striker (จอมทัพ)*:
   * ราคา 2500 | คูลดาวน์ 26s | HP 3500 | ATK 1150
   * ร่างปลดปล่อยเกราะทองสยายปีก บินพุ่งแทงหอกพลังทำลายล้างมหาศาล

## 👹 ฝั่งศัตรู (Enemy Units)

1. **Bandit (โจรลูกน้อง)**: กองโจรธรรมดา วิ่งกวนๆ เป็นฝูง (Fodder)
2. **Hunter (โจรนักธนู)**: โจมตียิงธนูจากระยะไกล
3. **Monk (หลวงจีน)**: นักสู้หมัดหนัก วิ่งไว
4. **Demon King Julian (บอสใหญ่)**:
   * จอมมาร Julian ร่างยักษ์ระดับตำนานของ LF2
   * ปรากฏตัวเมื่อป้อมศัตรูเลือดลดเหลือ 70% พร้อมปล่อย **คลื่นช็อกเวฟกระแทกยูนิตฝั่งเราทั้งหมดถอยหลัง!**
